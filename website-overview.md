# Website Overview

The website provides two ways for the user to get help with their PC or desktop:

1. **Manual Data Entry**
2. **Chat-Based Agent**

## 1. Manual Data Entry

The user first enters the required system information.

After entering the details, a small **“Diagnostics”** button becomes visible.

When the user clicks **Diagnostics**, the system provides **basic diagnostics**.

### If an anomaly is found

The system identifies and mentions the **damaged or affected part** and provides the diagnostic information, including the **three factors**.

### If no anomaly is found

The system displays that:

**“Basic diagnostics completed, all fine.”**

It then suggests using the **chat** for advanced diagnostics.

---

## 2. Chat-Based Agent

The user can also directly use the **chat-based agent** to seek help about their PC or desktop issue.

The diagnosis is done **inside the chat interface itself**.

After the user asks for help about an issue, the agent will **run the test** and provide the diagnosis.

### If the agent cannot answer the user's query

The issue is given to an **admin**, and the admin provides a **live reply to the user's issue in the chat**.

The agent will then **learn from the admin's response**.

---

## 3. Final Action After Diagnosis

Based on the diagnosis, the system provides one of three options:

### Repair

If the PC or desktop needs repair, the user can **book a PC or desktop technician**.

### Reuse

If the system can be reused, the application suggests **other useful purposes for the working components**.

### Recycle

If the system should be recycled, the agent suggests that the user give it to **E-waste recycling organizations**.

## Complete Website Flow

**Manual Data Entry / Chat-Based Agent**

↓

**Diagnostics**

↓

**Basic Diagnostics / Chat-Based Diagnosis**

↓

**Anomaly Found?**

→ **Yes:** Mention the damaged or affected part and the three factors.

→ **No:** Show that basic diagnostics are completed and all is fine, then suggest using the chat for advanced diagnostics.

↓

**If the Chat Agent Cannot Answer → Admin Live Reply → Agent Learns From the Reply**

↓

**Final Decision**

**Repair → Book PC/Desktop Technician**

**Reuse → Suggest Other Uses for Working Components**

**Recycle → Suggest E-waste Recycling Organizations**
